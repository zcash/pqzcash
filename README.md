# Post-Quantum Zcash

This repository holds design work towards post-quantum security for Zcash: the candidate
proof systems and commitment schemes, and the analyses that compare them. It will
eventually include formal verification of the claims made about them. The book is the
primary document. The models, data and notes that it draws on live beside it in this
repository.

## Documentation

- [The Post-Quantum Zcash Book](https://zcash.github.io/pqzcash/), built from `book/` and
  published by the book workflow. The link is not live while the repository is private.
